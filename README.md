# SOC Interview Trainer PWA

PWA statica, offline, pentru telefon si desktop. Interfata foloseste un stil dark cinematic inspirat de aplicatiile de streaming.

## Rulare locala

Din acest folder:

```bash
python -m http.server 8080
```

Deschide:

```text
http://localhost:8080
```

Pentru telefon, foloseste IP-ul PC-ului in aceeasi retea Wi-Fi:

```text
http://<IP_PC>:8080
```

## Instalare pe telefon

- Android Chrome/Edge: deschide URL-ul, apoi `Add to Home screen` / `Install app`.
- iPhone Safari: deschide URL-ul, Share, apoi `Add to Home Screen`.
